# Support

## Questions and installation help

Use [GitHub Discussions](https://github.com/thienqo/flutter-skills/discussions) for questions about installing or using these Agent Skills.

## Report a problem

Use the repository's issue forms for reproducible defects or focused feature requests. Include the affected skill or component, version, installation source, and minimal reproduction. Do not include credentials, private application data, or other sensitive information.

## Security concerns

Follow [SECURITY.md](SECURITY.md) to report suspected vulnerabilities. Do not post vulnerability details in public issues or discussions.

## Scope

This project maintains the Agent Skills collection, its installer, and its distribution metadata. It does not provide support for individual Flutter applications built with the skills; report application-specific issues to the maintainers of those applications.
